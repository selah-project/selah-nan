# 希伯來聖經(塔納赫)— 台語譯本

希伯來聖經(塔納赫)譯做台語(台灣閩南語,漢字書面) —
逐節逐節、逐字逐字,每一个希伯來字下面攏有台語解說。

這是 Selah 工程的**第七十一塊椅仔** — 第一塊台語椅仔,
用漢字寫的口語台文:伊/𪜶/毋/袂/佮/佇,毋是華語的
他/不/沒/們。倉庫:`selah-nan`。

## 希伯來文行代先

這个譯本是欲𤆬你去到希伯來原文 — 毋是欲取代伊。
你讀的是希伯來文:遐的字母、遐的音、遐的記號。
下跤彼逝台語是一扇窗仔,毋是替身。
兩爿若有出入,以希伯來文為準。

## 這个譯本毋是啥物

- **毋是你彼本聖經的替代品。** 留你彼本聖經,讀伊,
  佮伊祈禱。這份工課徛佇邊仔 — 指向希伯來原文。
- **毋是教義。** 干焦原文,逐字逐字,每一節攏查證會著。

看 `NOTES.md` 有封印的記錄,`manifest.edn` 有承傳的世系。
